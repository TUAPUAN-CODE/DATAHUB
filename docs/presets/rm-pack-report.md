# ชุดตั้งต้น: รายงาน RM บรรจุ (เทียบหน้า `ReportRawmatPackuser` ของระบบเดิม)

ชุดนี้ช่วยให้ชีตใหม่ออกรายงานแบบเดียวกับหน้า Report เดิม: ตารางเวลาเข้า-ออกห้องเย็น + DBS 1–4 + หัวฟอร์ม Date/Shift/Line/Plant + ช่องลงชื่อ 3 ช่อง

> ตัวเลข DBS 1–4 ในสูตรด้านล่างตรงกับโค้ดเดิม (Pack/ReportRawmatNotEditTIME/Asset/Table.jsx) **เฉพาะวัตถุดิบกลุ่มมาตรฐาน**
> ทดสอบเทียบกับโค้ดเดิมที่พอร์ตมาแล้วด้วยข้อมูลสุ่ม 400 แถว (`server/src/modules/formula/pfcmParity.test.ts`)
> กลุ่มพิเศษ (`rm_group_id` = 55, 85, 49, 46, 82) ที่ระบบเดิมแมปคอลัมน์ใหม่ ยังไม่ได้ทำเป็นสูตร (ดูหัวข้อท้ายเอกสาร)
> รูปแบบ PDF เป็นจุดเริ่มต้นที่ใกล้เคียง ไม่ใช่การจำลองทุกพิกเซลของฟอร์มเดิม ปรับต่อได้ในหน้า “ออกแบบรูปแบบ PDF”

## 1) ชีต `RM Report` — คอลัมน์ที่ต้องมี

คอลัมน์ข้อมูล (กรอก/นำเข้า/มาจาก RFID ตามที่ตั้ง):

| ชื่อคอลัมน์ | ชนิด | หมายเหตุ |
|---|---|---|
| รายการ | ข้อความสั้น | = `mapping_id` เดิม |
| แผนการผลิต, รายชื่อวัตถุดิบ, Batch, ชุดที่, หมายเหตุ | ข้อความสั้น | |
| น้ำหนักวัตถุดิบ | ทศนิยม | |
| เวลาเตรียมเสร็จ (A) | วันที่และเวลา | |
| เข้าห้องเย็น 1 / ออกห้องเย็น 1 | วันที่และเวลา | |
| เข้าห้องเย็น 2 / ออกห้องเย็น 2 | วันที่และเวลา | |
| เข้าห้องเย็น 3 / ออกห้องเย็น 3 | วันที่และเวลา | ไม่แสดงในฟอร์ม แต่ใช้คำนวณ |
| บรรจุเสร็จ (F) | วันที่และเวลา | |
| นาทีรอผลิต (ฝากเก็บ) | ทศนิยม | ผลรวมนาทีที่ฝากเก็บเพื่อรอผลิต (0 ถ้าไม่มี) |

## 2) คอลัมน์สูตร (เปิด “คำนวณค่าอัตโนมัติด้วยสูตร” ในตั้งค่าคอลัมน์)

ลำดับการสร้าง: ชนิด **ทศนิยม** 4 คอลัมน์ก่อน แล้วคอลัมน์แสดงผลเป็น **ข้อความสั้น**

| คอลัมน์ | ชนิด | สูตร |
|---|---|---|
| `DBS1 (นาที)` | ทศนิยม | `MINUTES([เวลาเตรียมเสร็จ (A)], [เข้าห้องเย็น 1])` |
| `DBS2 (นาที)` | ทศนิยม | `IF(COUNT(MINUTES([เข้าห้องเย็น 1], [ออกห้องเย็น 1]), MINUTES([เข้าห้องเย็น 2], [ออกห้องเย็น 2]), MINUTES([เข้าห้องเย็น 3], [ออกห้องเย็น 3]), IF([นาทีรอผลิต (ฝากเก็บ)] > 0, [นาทีรอผลิต (ฝากเก็บ)], BLANK)) = 0, BLANK, SUM(MINUTES([เข้าห้องเย็น 1], [ออกห้องเย็น 1]), MINUTES([เข้าห้องเย็น 2], [ออกห้องเย็น 2]), MINUTES([เข้าห้องเย็น 3], [ออกห้องเย็น 3]), IF([นาทีรอผลิต (ฝากเก็บ)] > 0, [นาทีรอผลิต (ฝากเก็บ)], 0)))` |
| `DBS3 (นาที)` | ทศนิยม | `IF(ISBLANK(MINUTES([ออกห้องเย็น 1], [บรรจุเสร็จ (F)])), BLANK, MAX(0, MINUTES([ออกห้องเย็น 1], [บรรจุเสร็จ (F)]) - SUM(MINUTES([เข้าห้องเย็น 2], [ออกห้องเย็น 2]), MINUTES([เข้าห้องเย็น 3], [ออกห้องเย็น 3]))))` |
| `DBS4 (นาที)` | ทศนิยม | `IF(AND(ISBLANK([DBS1 (นาที)]), ISBLANK([DBS3 (นาที)])), MINUTES([เวลาเตรียมเสร็จ (A)], [บรรจุเสร็จ (F)]), SUM([DBS1 (นาที)], [DBS3 (นาที)]))` |
| `DBS 1` | ข้อความสั้น | `COALESCE(DURATION([DBS1 (นาที)]), "-")` |
| `DBS 2` | ข้อความสั้น | `COALESCE(DURATION([DBS2 (นาที)]), "-")` |
| `DBS 3` | ข้อความสั้น | `COALESCE(DURATION([DBS3 (นาที)]), "-")` |
| `DBS 4` | ข้อความสั้น | `COALESCE(DURATION([DBS4 (นาที)]), "-")` |

ผลลัพธ์แสดงเป็นรูปแบบเดิม เช่น `2 h 30 m` (0 นาที = `-`)

## 3) นำเข้ารูปแบบ PDF

1. เปิดไฟล์ที่มีชีต `RM Report` → เมนู ⋯/ดาวน์โหลด → “ออกแบบรูปแบบ PDF…”
2. กด “นำเข้า (.json)” แล้วเลือก `rm-pack-report.template.json` (ตารางจับคู่ชีตและคอลัมน์ตาม **ชื่อ** จึงต้องตั้งชื่อตรงตามด้านบน)
3. เวลา export ระบบจะถาม Date (เริ่มต้นวันนี้), Line, Plant และชื่อผู้ลงนาม 3 ช่อง; Shift คำนวณเป็น DS/NS ตามเวลา (06:00–18:00 = DS — ปรับได้ในตั้งค่ากระดาษ)
4. ติ๊ก “บันทึกสำเนาเก็บเข้าระบบ” เพื่อเก็บ PDF ที่ลงชื่อแล้วไว้ในเมนู “เอกสารที่ออกแล้ว” (เทียบกับการอัปโหลด PDF ของหน้าเดิม)

## 4) สิ่งที่ยังไม่ครอบคลุม (ต้องตัดสินใจ/ข้อมูลเพิ่ม)

- **กลุ่มพิเศษ** (`rm_group_id` 55 / 85 / 49 / 46 / 82): ระบบเดิมแมปเวลา A–F จากคอลัมน์อื่น (เช่น `gm_date`, `start_mixed_date`, `rmit_date_mix`) และเปลี่ยนสูตร DBS ทำเป็นสูตรได้ด้วย `IF([กลุ่มวัตถุดิบ] = 55, …)` เมื่อมีคอลัมน์เหล่านั้นในชีตแล้ว — ต้องยืนยันความหมายของแต่ละกลุ่มก่อนเขียน
- **คู่เข้า-ออกห้องเย็นรอบที่ 4–6** (ห้องเย็นใหญ่ `cs_*`) เรียงตามเวลาเข้า: ชีตนี้รองรับ 3 รอบ; ถ้าต้องการ 6 รอบให้เพิ่มคอลัมน์เองหรือใช้ชีต “รอบห้องเย็น” แยก (ตามแนวคิดในเอกสารออกแบบ)
- การแก้เวลาในหน้าตัวอย่างก่อน export (หน้าเดิมทำได้) — ระบบใหม่ให้แก้ในชีตโดยตรง (มีประวัติ/สิทธิ์/ย้อนค่าได้) แล้วค่อย export ใหม่
